# アンラッキーモンスター 太鼓風 (Web)

参照動画: <https://www.youtube.com/watch?v=v99Z_jmP9d0>
（OpenTaiko の創作譜面「アンラッキーモンスター」）

単一 HTML の太鼓の達人風リズムゲーム。ブラウザで開くだけで動く。

## 遊び方

- `games/taiko/index.html` をブラウザで開く
- Play! を押して開始
- 赤い音符（DON）: `F` / `J` キー、または画面下の赤ボタン
- 青い音符（KA）: `D` / `K` キー、または画面下の青ボタン
- 判定ラインで叩くとスコア加算。PERFECT / GOOD / BAD の3段階

## 実装メモ

- BPM 180 前後の 16 beat 創作譜面（動画本家の譜面データではなくオマージュ）
- Web Audio API でメロディと打撃音を合成。外部音源ゼロ
- Canvas 2D で描画。追加ライブラリなし
- スマホの物理キーが無い環境向けに画面下にパッドを配置
