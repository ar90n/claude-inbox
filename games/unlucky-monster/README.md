# アンラッキーモンスター RPG (Web)

参照動画: <https://www.youtube.com/watch?v=v99Z_jmP9d0>
（カラフルピーチ「アンラッキーモンスター」／ヒロ × たっつん × もふ × どぬく）

原曲は「1UP・コンティニュー・レベル上げ・ボス倒し」など RPG モチーフを織り込みつつ、
「魔法も勇者も宝の地図も無い」「データ吹っ飛び初期化」などの不運を並べた楽曲。
その世界観を **単一 HTML の疑似 RPG** にした。

## 遊び方

- `games/unlucky-monster/index.html` をブラウザで開く
- 「たたかう」（`A` / `Enter` / `Space`）でパーティ攻撃
- 「まもる」（`G`）で次の被ダメ半減
- 「まほう」「どうぐ」は封印（曲のとおり魔法も道具も無い）
- HP 0 で気絶。全員気絶で GAMEOVER
- **コンティニュー3回** まで復活可能。ボスは5階ごと
- 到達フロアが最終スコア

## 世界観の反映

- 攻撃 10% で MISS、通行止め、落とし穴、セーブデータ吹っ飛び、レベル奪取など
  「アンラッキー」イベントが挟まる
- ゴースト・スロットの特殊「wipe」で EXP を持っていかれる
- 借金天狗の特殊で Lv 剥奪
- 弁慶ボア（ボス）は 5, 10, 15F ごとに出現

## 実装

- 単一 HTML、外部依存なし
- 絵文字スプライトのみ（画像素材ゼロ）
- CSS アニメーション（ヒット振動、被弾フラッシュ、ダメージポップ）
