# アンラッキーモンスター — WORLD 1-1

元ネタ: <https://www.youtube.com/watch?v=v99Z_jmP9d0>
（カラフルピーチ「アンラッキーモンスター」／ヒロ × たっつん × もふ × どぬく）

この MV は **レトロな横スクロールアクションゲームの画面** を模した映像で、
画面上部に「ハート × 5／WORLD 1-1／Unlucky Monster／Colorful Peach」の HUD、
下部にドット絵の草＋土の地面、背景に階段状のブロック雲、
そしてタイトルロゴの横に大きなドット星が置かれている。

その画面をそのまま **遊べるゲーム** にしたファン作品。

`games/unlucky-monster/index.html` をブラウザで開くだけで動く。

## 遊び方

| 操作 | キー | スマホ |
|---|---|---|
| 移動 | `←` `→` | ◀ ▶ |
| ジャンプ | `Z` / `SPACE` / `↑` | ▲ |
| ダッシュ | `SHIFT` / `X` | ≫ |
| キャラ選択 | タイトルで `←` `→` | 画面タップで開始 |
| リトライ | `R` | — |
| BGM ON/OFF | `M` | — |

- ハート5つが体力。0 で GAME OVER
- 歩行モンスターは踏むと倒せる。トゲモンスターは踏めないので避ける
- コイン20枚ごとに 1UP（ハート回復）
- スターを取ると一定時間無敵＆レンガも壊せる
- 穴に落ちるとハート -1、直前のセーブ地点から再開

## MV から取り込んだ要素

- **HUD** — ハート5つ（4人のイメージカラー＋1）／`WORLD 1-1`／`UNLUCKY MONSTER`／`COLORFUL PEACH` の並びを再現
- **地面** — 明るい草の帯 + ドットの刻み + 茶色の土
- **雲** — 階段状のブロック雲を2層パララックスで
- **星** — タイトルロゴ横の大きなドット星。ゲーム中は無敵アイテムとゴール旗にも
- **タイトル画面** — サムネイルと同じく4人が地面に並ぶ構図

## 「アンラッキー」の仕掛け

曲名にちなんで、**見た目が普通の `?` ブロックと全く区別がつかないハズレブロック**を仕込んである。
叩くとアイテムではなく時限爆弾が出てきて `UNLUCKY!` が表示される。
（爆風はモンスターも巻き込むので、うまく使えばラッキーにもなる）

## 実装

- 単一 HTML・外部素材ゼロ。画像も音源も読み込まない
- ドット絵は全て Canvas の矩形描画で生成（キャラ・敵・タイル・5x7 ビットマップフォント）
- BGM と効果音は Web Audio API で合成したオリジナルのチップチューン
- ステージは 25 タイル幅のセグメント配列を連結して生成（`SEGMENTS`）。
  行数が足りない分は下端そろえで自動パディングされるので、追記・編集しやすい
- 物理は 60fps 固定ステップ。コヨーテタイム / ジャンプ先行入力 / 可変ジャンプ高さ付き

## 検証

ヘッドレス Chromium で以下を確認済み。

- JS エラーなしで起動（タイトル／プレイ／ゲームオーバー／ステージクリア）
- 全ての穴・足場が **ダッシュ無しの歩き速度でも** クリア可能
- ゴール到達で STAGE CLEAR に遷移
- スマホ幅で操作パッドが表示され、画面と重ならない

## ことわり

キャラクターのドット絵は MV の4人をイメージした**オリジナルの配色・デザイン**で、
公式の素材やキャラクターデザインを複製したものではない。
BGM も原曲とは無関係の自作チップチューン。非公式のファン作品。
